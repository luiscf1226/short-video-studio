# Platform adaptation

## Studio defaults

Use a clean 9:16 1080×1920 master, H.264/yuv420p video, AAC audio, and faststart MP4. Start at 30 fps unless footage or the requested delivery needs another rate. The 30–45 second target is a production choice, not the maximum on any platform. Treat -14 LUFS as this studio's starting audio target, not a guaranteed normalization rule across platforms.

Keep captions short and readable on a phone. Avoid interface overlays around the top, bottom and right; inspect current platform previews rather than claiming a universal fixed safe zone. Center essential cover text and inspect feed/profile cropping. Prepare both captioned and clean variants only if useful. Never download a watermarked social upload to serve as the cross-platform master.

## Copy

- YouTube Shorts: descriptive title with the viewer problem/result; short supporting description. Add relevant hashtags only when useful.
- TikTok: conversational caption with relevant searchable language; a real question if comments serve the video's goal.
- Instagram Reels: clear opening caption, useful context, and a save/share CTA when the video justifies it.

These are editorial choices, not algorithm guarantees. Reuse the actual content; tailor packaging without promising different facts. Use original or appropriately licensed music; an in-app soundtrack's license may not cover other platforms. Trend research is optional and needs current evidence relevant to the niche.

## Live specifications

Platform limits and publishing integrations change. Consult official guidance when current eligibility, duration limits or API upload constraints matter; record the date and source in the delivery. The following official pages were consulted 2026-09-30:

- [YouTube: understand three-minute Shorts](https://support.google.com/youtube/answer/15424877): square/vertical videos up to three minutes fall within the described Shorts classification rules.
- [TikTok: editing, posting and deleting](https://support.tiktok.com/en/using-tiktok/creating-videos/editing-posting-and-deleting): native editing and posting workflow.
- [Meta Instagram Reels publishing reference](https://www.postman.com/meta/instagram/folder/f95kq5e/reels-publishing): Meta's API publishing documentation recommends 9:16. API requirements should not be presented as universal native-app limits.

Never claim a post was scheduled/published merely because its planned date/time appears in a file.
