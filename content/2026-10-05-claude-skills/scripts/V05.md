Fecha propuesta: 2026-10-09. Formato: FAQ visual. Duración objetivo: 40 s; ensayar para ajustar a 30–45 s. Estado: planificado.

Promesa: Dónde guardar una skill. Gancho alternativo: «Antes de mover tu skill, piensa dónde la necesitas.».

## Guion hablado

¿Tu skill es para un proyecto o para todos? En Claude Code puedes guardarla en la carpeta punto claude, skills del proyecto, o en esa carpeta dentro de tu directorio personal. En pantalla comparo las dos rutas. Para nuestro ejemplo usaré la del proyecto, así mantenemos juntos el archivo y la demostración. Cuando compartas una skill, explica dónde colocarla y cómo probarla. Revisa también lo que contiene antes de ejecutarla. Guarda esta comparación si te confunden las carpetas.
