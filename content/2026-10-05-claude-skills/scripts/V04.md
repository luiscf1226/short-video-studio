# V04 — Cómo usar tu skill en Claude Code

Fecha propuesta: 2026-10-08. Formato: Demo de uso. Duración objetivo: 40 s; ensayar para ajustar a 30–45 s. Estado: planificado.

Promesa: Cómo usar tu skill en Claude Code. Gancho alternativo: «Así probaría una skill recién creada.».

## Guion hablado

Ya tienes la skill. Ahora toca probarla. Abre Claude Code en el proyecto del ejemplo y escribe barra ideas-short, seguido del tema: skills para principiantes. En pantalla muestro la petición y reviso la respuesta real. Busco tres ideas distintas, un gancho claro y una demostración que pueda grabar. Si falta algo, lo anotamos para mejorar las instrucciones. El nombre del comando debe coincidir con nuestra skill. Guarda esta prueba para revisar la tuya cuando la crees.
