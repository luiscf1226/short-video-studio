# V03 — Crea tu primera skill: ideas para shorts

Fecha propuesta: 2026-10-07. Formato: Mini tutorial. Duración objetivo: 40 s; ensayar para ajustar a 30–45 s. Estado: planificado.

Promesa: Crea tu primera skill: ideas para shorts. Gancho alternativo: «Vamos a crear una skill pequeña para preparar contenido.».

## Guion hablado

Tu primera skill puede empezar con este archivo. En un proyecto de Claude Code, preparo la carpeta ideas-short dentro de punto claude, skills. Ahí guardo SKILL punto md. Le doy un nombre, una descripción y unas instrucciones: proponme tres ideas en español, con gancho, demostración y una acción final. En pantalla te dejo el ejemplo completo para pausar y leerlo. Esta primera versión hace una sola tarea. Después la probaremos con un tema concreto. Guarda el video para intentarlo.
