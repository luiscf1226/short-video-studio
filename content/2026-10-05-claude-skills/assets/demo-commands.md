# Comandos para la grabación

Desde la raíz del repositorio, entrar al proyecto de demo:

```bash
cd content/2026-10-05-claude-skills/assets/claude-demo
claude
```

Dentro de Claude Code, escribir uno por vez:

```text
/ideas-short skills para principiantes
```

Segunda prueba:

```text
/ideas-short herramientas de IA para estudiar
```

Prueba sin tema (debería hacer una pregunta):

```text
/ideas-short
```

Para la entrevista del video studio, usar una conversación nueva y escribir:

```text
/short-video-studio Quiero planear una semana de videos. Entrevístame primero sobre los temas y espera mis respuestas antes de crear el calendario.
```

La carpeta tiene ambas skills preparadas para el proyecto. Claude Code está instalado y la sesión aparece autenticada; no se ejecutaron estas consultas ni se garantiza su resultado. Grabar la respuesta real y revisar si coincide con lo pedido. Las consultas utilizan tu cuenta de Claude Code.

Para V01 basta mostrar el archivo y su sección de entrevista; no es necesario ejecutar una consulta.
